# 🎓 Student Performance Analytics Dashboard

## 📌 Project Overview

This project is an Excel-based Student Performance Analytics Dashboard developed to analyze academic outcomes, behavioral factors, demographic characteristics, and learning patterns.

The dashboard transforms student performance data into meaningful insights using Microsoft Excel and Power Query for data cleaning, transformation, analysis, and visualization.


# 🎯 Objectives

- Analyze student exam performance across different categories.
- Evaluate the relationship between study hours and academic outcomes.
- Compare performance based on gender and school type.
- Understand how motivation levels influence exam scores.
- Analyze the impact of attendance and parental involvement.
- Generate actionable recommendations to improve student achievement.

# 🔎 Key Insights

1. Higher motivation levels are associated with improved exam scores, showing the importance of student engagement.

2. Similar average scores across school types suggest school type alone has limited influence on academic performance.

3. Exam scores increase with study hours, indicating a positive relationship between learning effort and achievement.

4. Teacher quality shows smaller score differences, suggesting multiple factors contribute to student outcomes.

5. The minimal gender performance gap indicates academic performance is largely gender-neutral within the dataset.


# 💡 Recommendations

1. Develop programs that improve student motivation and academic engagement.

2. Encourage consistent study routines to support better exam performance.

3. Provide targeted support for students with lower motivation levels.

4. Combine teacher development with stronger student engagement strategies.

5. Focus educational improvements on learning behaviors rather than demographic differences.
